## 1. Dashboard Agent Avatars

### team-grid.png (Required)

| Property      | Value                                                  |
| ------------- | ------------------------------------------------------ |
| **Location**  | `docs/agents/images/team-grid.png`                     |
| **Format**    | PNG                                                    |
| **Layout**    | 2-row grid: 5 agents top, 4 agents bottom              |
| **Used by**   | `tools/process-avatars.js` (face detection extraction) |
| **Generates** | 9 headshots in `docs/agents/images/headshots/`         |

**Agent order (left-to-right, top-to-bottom):**

| Position | Row    | Agent     | Role               |
| -------- | ------ | --------- | ------------------ |
| 1        | Top    | Conductor | DM / Orchestrator  |
| 2        | Top    | Compass   | Product Owner      |
| 3        | Top    | Keystone  | Architect          |
| 4        | Top    | Lens      | Code Reviewer      |
| 5        | Top    | Palette   | UI Designer        |
| 6        | Bottom | Forge     | Backend Developer  |
| 7        | Bottom | Pixel     | Frontend Developer |
| 8        | Bottom | Sentinel  | Functional Tester  |
| 9        | Bottom | Circuit   | Automation Tester  |

> The grid layout is configured in `agents.config.json` under `orchestrator.avatarGrid`.

### team.png (Optional)

| Property     | Value                         |
| ------------ | ----------------------------- |
| **Location** | `docs/agents/images/team.png` |
| **Format**   | PNG                           |
| **Used by**  | Dashboard "About" modal popup |

Full team photo shown when users click the About button on the SDLC dashboard.

### Individual Agent Images (Optional)

| Property     | Value                                                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Location** | `docs/agents/images/{name}.png`                                                                                                    |
| **Names**    | `conductor.png`, `compass.png`, `keystone.png`, `lens.png`, `palette.png`, `forge.png`, `pixel.png`, `sentinel.png`, `circuit.png` |
| **Used by**  | Dashboard spotlight banner (fallback if headshot missing)                                                                          |

Landscape-style images used in the active agent spotlight banner. These are the middle tier in the dashboard's 3-tier fallback chain:

1. **Headshot** (`headshots/{name}.png`) — circular crop from team-grid
2. **Full image** (`{name}.png`) — individual agent landscape image
3. **Emoji** — from `agents.config.json` icon field

## 3. Build Commands

| Command             | What It Does                                                 |
| ------------------- | ------------------------------------------------------------ |
| `npm run avatars`   | Extracts headshots from `team-grid.png` using face detection |
| `npm run dashboard` | Generates `docs/dashboard.html` with agent avatars           |
| `npm run build`     | Runs avatars + plan generation + dashboard (full pipeline)   |

### Extraction Pipeline

```
team-grid.png
    ↓  npm run avatars (tracking.js Viola-Jones face detection)
headshots/{name}.png  (9 files, 200×200 px)
    ↓  npm run dashboard (generate-dashboard.js)
docs/dashboard.html   (avatars with 3-tier fallback)
```

### Customizing Face Detection

```bash
# Adjust padding around detected faces (default: 1.5x)
node tools/process-avatars.js --padding 2.0
```

---

## 4. Naming Rules

- All filenames must be **lowercase** (e.g., `conductor.png`, not `Conductor.PNG`)
- `process-avatars.js` does case-insensitive lookup and auto-renames to lowercase
- Agent names come from `agents.config.json` — the keys in the `agents` object
- If you add/remove agents, update `agents.config.json` and the grid image accordingly
